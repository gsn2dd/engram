==============================================================================
  WELCOME TO YOUR OWN AI ASSISTANT SERVER
==============================================================================

This server is yours. It runs an AI assistant (Claude) with a memory of its
own, called engram. Everything you tell it, and everything it learns working
with you, stays on THIS server -- not in a shared cloud account.

It remembers across conversations. Tomorrow it will know what you decided
today, and why. The longer you work with it, the more useful it becomes.


------------------------------------------------------------------------------
  FIRST TIME?  Type this and press Enter:

        start

------------------------------------------------------------------------------

`start` walks you through it, one step at a time:

  1. Its memory. You paste one free key (from Google AI Studio) so it can
     store and find memories. `start` shows you where to get it.

  2. The assistant. It installs Claude and asks you to sign in with your own
     Claude account (a Claude Pro or Max plan, or an Anthropic API key).

  3. Then you are talking to it. Say hello, tell it who you are and what you
     want help with. It writes down what matters, by itself.

You only do steps 1 and 2 once.


------------------------------------------------------------------------------
  EVERY DAY AFTER THAT
------------------------------------------------------------------------------

  Log in, type   start   and you are back with your assistant, memory and all.

  To leave the assistant:   type  /exit   (or press Ctrl+C twice)
  To leave the server:      type  exit


------------------------------------------------------------------------------
  GOOD TO KNOW
------------------------------------------------------------------------------

  * Lost?             type   get_started   for the full guide and status checks
  * Your data         lives on this server's disk. Back it up with an EBS
                      snapshot in the AWS console (your server's volume).
  * Keys and passwords are never shown on screen and never leave this server.
  * Costs             this server (AWS, by the hour while it runs) and your
                      Claude plan. The Google memory key has a free tier.
                      Stop the server in the AWS console when you are away
                      for a long time; your memories are kept.
  * Copying text      in PuTTY: select with the mouse to copy, right-click to
                      paste.
